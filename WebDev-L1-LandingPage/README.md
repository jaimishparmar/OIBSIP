
# NEXORA — Premium Technology Landing Page

## About
NEXORA is a fictional premium technology brand. This responsive landing page presents a modern technology-focused design using HTML5 and CSS3.

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- CSS Grid and Flexbox

## Features
- Sticky navigation bar
- Hero section with call-to-action buttons
- Product illustration created with CSS
- Features section with three cards
- About section
- Footer with navigation and contact link
- Responsive desktop and mobile layouts

## How to Run
1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
